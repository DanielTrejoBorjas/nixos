# CLAUDE.md

## Code Quality
- Write clean, readable, maintainable code.
- Use clear, descriptive names for variables, functions, and files.
- Keep functions small and single-purpose.
- Follow the existing style and conventions of the project.
- Avoid duplication; reuse existing code before writing new code.

## Project Structure
- Create all files needed for the task.
- Create all directories needed; keep the structure organized.
- Place files in the correct directory by responsibility.

## Workflow
- Build in small, incremental parts.
- Finish and verify each part before moving to the next.
- Do not implement features that were not requested.

## Comments
- Only comment what the code cannot say by itself (why, not what).
- Keep comments short and direct.
- No comments that restate obvious code.
- No decorative or over-explanatory comments.

## Responses
- Be concise. No unnecessary explanations.
- No long introductions or summaries.
- Only explain when asked or when a decision is non-obvious.
- Ask only when blocked; otherwise state assumptions in one line and proceed.

## Safety
- Do not delete or overwrite existing files without need.
- Do not install dependencies unless required.
- Do not modify unrelated code.
